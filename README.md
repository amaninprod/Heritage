## 📖 Overview

**Heritage** is a heritage site showcase website featuring historical monuments and cultural landmarks. It displays information about heritage sites with images and descriptions.

> 🎯 **Purpose:** Heritage/cultural site showcase website

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏛️ **Heritage Showcase** | Display historical monuments |
| 🖼️ **Image Gallery** | High-quality heritage site images |
| 📄 **Information Pages** | Detailed site information |
| 📱 **Responsive** | Works on all devices |
| 🎨 **Clean Design** | Simple, elegant layout |
